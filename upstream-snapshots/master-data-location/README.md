# Native Master Data location support

Exact unmodified upstream chart source at the revision in SOURCE.json, matching
Farmer's develop.118 location API. This is a bundled source snapshot, not a claim
that a develop.118 Helm release exists. Only generated dependency locks/archives
are added to this source. OAN overrides stay in the Commons parent chart.

Existing Master Data geography, catalogues, IAM policies and AWE tasks require
restored-data upgrade verification before Commons promotion. Geo seeding is off
by default; no automatic geography replacement, sample loading or publication.
ETH-OAN/agriculture is an explicit administration prerequisite. Existing geographic
assignments are retained and migrated through supported administration.
